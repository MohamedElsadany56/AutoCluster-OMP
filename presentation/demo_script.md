# Demo Script

1. Install the package with `pip install -e .`.
2. Analyze `c_kernels/kmeans/kmeans_seq.c`.
3. Show the JSON loop report and the safe assignment-loop decision.
4. Generate `kmeans_auto_omp.c`.
5. Benchmark sequential, manual OpenMP, and generated OpenMP versions.
6. Plot runtime, speedup, and efficiency.
7. Repeat generation and benchmarking for Fuzzy C-Means.
